A2A Platform TUI

一个暗色终端风格的远程监测与控制系统，用于管理 A2A (Agent-to-Agent) 生态中的 Bridge 代理。支持实时 SSE 事件流、三态健康检测与键盘驱动操作。

● 服务端运行中 ● 3 agents online Go 1.22 Node.js 18+ Bubble Tea

下游服务

a2a-platform-go

核心平台服务端，管理 Agent 注册、任务路由、Trace 追踪。

  • REST API: /api/agents, /api/tasks, /api/traces
  • SSE 实时流: /api/events
  • 统计聚合: /api/stats
  • MySQL 持久化 + 内存 Registry
  • 三态健康检测（30s 周期）

a2a-tui

独立的终端 UI 客户端，远程连接平台进行监控与控制。

  • Bubble Tea + Lipgloss 暗色主题
  • Tab 切换: Agents / Tasks / Traces / Events
  • 实时 SSE 事件流
  • 键盘驱动: n注册 d删除 enter详情 r刷新
  • 独立的 Go module 与二进制

a2a-bridge

外部 Node.js 代理，将任意 HTTP API 或 CLI 封装为 A2A 协议。

  • Agent Card: /.well-known/agent.json
  • 健康探测: /-/health（探测下游 LLM）
  • 热重载配置
  • HTTP / CLI 双模式调用

核心功能

📡

SSE 实时事件流

服务端通过 /api/events 推送 agent 状态变更、task 生命周期、trace 事件，TUI 实时接收并更新视图。

🩺

三态健康检测

区分 online（全链路健康）、offline（bridge 不可达）、unreachable（bridge 活着但 LLM 挂了）。

🖥️

暗色终端主题

参考 OpenAgents 风格，#0d1117 背景、状态色编码、自适应列宽、viewport 滚动。

⌨️

键盘驱动控制

Tab 切换视图、↑↓ 选择、Enter 查看详情、n 注册 agent、d 删除、r 刷新、q 退出。

🌐

远程连接

TUI 作为独立二进制，通过 HTTP API + SSE 连接任意远程 a2a-platform 实例。

🔄

自动恢复

Offline agent 的 bridge 恢复后，平台在下一轮 health check 自动重连，无需人工干预。

三态状态模型

平台 health check 采用两阶段探测，精确区分不同层级的故障：

状态 含义 触发条件 TUI 颜色
online / connected Bridge + LLM 都健康 Agent card 200 + HealthUrl 200 绿色
offline Bridge 完全不可达 Agent card 连接失败 / 非 200 红色
unreachable Bridge 活着，LLM 挂了 Agent card 200 + HealthUrl 非 200 黄色

连续 3 次失败才标记状态，避免抖动。恢复后自动重连。
