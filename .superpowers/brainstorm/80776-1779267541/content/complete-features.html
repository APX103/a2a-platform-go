完整功能列表（更新）

基于 mcp-conversation-engine + Kimi CLI subagent

核心功能模块

🗨️ 聊天模块

  • /chat/:agentName 路由，时间轴布局
  • Thinking 可折叠展示（分时间块）
  • Markdown 渲染（代码高亮、表格、引用）
  • 工具调用展示（参数 + 结果 + 链式调用）
  • SSE 流式响应处理

📁 Context 管理

  • 每个 Agent 多个 context 会话
  • /api/contexts/:agentName 列出会话
  • /api/contexts/:id 获取会话详情
  • 支持继续对话（基于 contextId）
  • 会话删除 API
  • 会话标题自动生成

🔧 内置工具

  • fetch_url（HTTP 请求）
  • web_search（需接入搜索 API）
  • tool_search（MCP 工具 schema 查询）
  • read_file / write_file / edit_file（文件操作）
  • list_directory（目录遍历）

🤖 Subagent 系统

  • spawn_agent 工具
  • 独立 context 隔离
  • Foreground/Background 两种模式
  • subagent_sessions 表
  • 禁止嵌套调用（1层深度）
  • 超时控制（5分钟）

数据库 Schema 变更

messages 表扩展
-- 新增字段
ALTER TABLE messages ADD COLUMN reasoning_content TEXT;
ALTER TABLE messages ADD COLUMN tool_calls JSON;
ALTER TABLE messages ADD COLUMN tool_call_id VARCHAR(64);
ALTER TABLE messages ADD COLUMN thinking_blocks JSON;
-- thinking_blocks 格式: [{"id":"t1","timestamp":123456,"content":"..."}]
contexts 表（新增）
CREATE TABLE contexts (
id VARCHAR(36) PRIMARY KEY,
agent_name VARCHAR(128) NOT NULL,
title VARCHAR(256),
message_count INT DEFAULT 0,
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
INDEX idx_agent (agent_name)
);
subagent_sessions 表（新增）
CREATE TABLE subagent_sessions (
id VARCHAR(36) PRIMARY KEY,
parent_context_id VARCHAR(36),
parent_tool_call_id VARCHAR(64),
task TEXT,
context TEXT,
status VARCHAR(16), -- running, completed, failed
messages JSON,
result TEXT,
error TEXT,
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
completed_at TIMESTAMP
);

技术选型

前端库

  • Markdown: react-markdown + remark-gfm
  • 代码高亮: react-syntax-highlighter 或 shiki
  • SSE: @microsoft/fetch-event-source (自动重连)
  • 状态: Zustand (轻量，易替换)

后端库

  • LLM: 保留现有 OpenAI/Anthropic provider
  • HTTP: Go 标准库 net/http + retryablehttp 可选
  • Web Search: 接口抽象，支持多种搜索 API

SSE 事件类型（扩展）

新增事件:
thinking.delta — Thinking 内容流式推送
thinking.block — Thinking 分块（带时间戳）
tool.call_start — 工具调用开始（含参数）
tool.call_delta — 工具参数流式推送
tool.call_end — 工具调用结束
tool.result — 工具执行结果
subagent.started — Subagent 启动
subagent.completed — Subagent 完成
subagent.error — Subagent 错误
