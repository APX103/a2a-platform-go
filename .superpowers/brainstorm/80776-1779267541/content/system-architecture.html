后端 API 端点（新增）

方法 路径 说明
GET/api/contexts/:agentName列出 Agent 的所有 context 会话
GET/api/contexts/:id获取 context 详情（消息列表）
DELETE/api/contexts/:id删除 context 会话
GET/api/messages/by-context/:contextId按 contextId 获取消息
GET/api/subagents/:contextId列出 context 的所有 subagent
GET/api/subagents/:id获取 subagent 详情

实施阶段规划

Phase 1

基础聊天界面 (1-2 天)

  • ChatPage 组件 + 时间轴布局
  • SSE 事件处理（text.delta, tool.call, tool.result）
  • Markdown 渲染
  • 输入框 + 发送功能
Phase 2

Thinking + 工具展示 (1-2 天)

  • Thinking 可折叠组件
  • Thinking 分时间块展示
  • ToolCallCard 完整展示
  • 工具调用链式关系可视化
Phase 3

Context 管理 (1-2 天)

  • contexts 表 + CRUD API
  • 会话列表侧边栏
  • 会话切换 + 继续对话
  • 会话删除功能
Phase 4

内置工具 + Subagent (2-3 天)

  • fetch_url, read_file, write_file 等工具
  • web_search 抽象接口
  • subagent_sessions 表
  • spawn_agent 工具 + 隔离 context
